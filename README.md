# Hashimiya Lectures in English

Unofficial English translations and narrations of lessons by Shaykh Abd al-Kabir al-Balghithi
from https://www.youtube.com/@tariqalhashimiya, published as a podcast.

- Feed: https://fardeem.github.io/hashimiya-lectures-english/feed.xml
- Site: https://fardeem.github.io/hashimiya-lectures-english/

Audio files are hosted as GitHub Release assets (one release per episode), not committed to git.
`episodes.json` is the source of truth; `tools/add_episode.py` regenerates `feed.xml` and `index.html`.
